# cookiecutter-fastapi

用于创建FastAPI项目模板。

## 重要提示

使用此项目时，您不需要fork它。只需运行cookiecutter CLI即可！

## Cookiecutter

Cookiecutter是一个CLI工具（命令行界面），用于从模板创建应用程序样板。它使用模板系统——Jinja2——来替换或自定义文件夹和文件名，以及文件内容。

### 如何安装？

```bash
pip install cookiecutter
```

### 如何生成FastAPI项目？

```bash
cookiecutter https://github.com/mr-pounds/cookiecutter-fastapi.git
```
